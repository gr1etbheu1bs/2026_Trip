2026/8/12(水)〜8/14(金)

南西先行か、北東先行かを決めるための日程比較

8/12は台風影響による一日雨を前提に、屋内で強い体験を1つ入れて、早めにホテルへ寄せる計画にします。施設の休館日、午前向きかどうか、ホテル位置を同じ画面で見ながら選べる形にしました。

8/12の前提 台風・一日雨

屋内施設を優先。川沿い・屋外歩行・満車リスクが高い施設は無理に入れない。

南西グループ JAXA / 相模川

12時出発ならJAXA相模原キャンパスを午後の軸にしやすい。相模川は雨と駐車場状況で外す候補。

北東グループ 多摩六都 / 立川

多摩六都科学館は午前到着が強い。立川防災館は8/13(木)休館なので候補日は8/12か8/14。

中間ノード サイエンスドーム

八王子にあり南西・北東どちらにもつなげやすい。15:50の花火番組が今回のテーマに合う。
