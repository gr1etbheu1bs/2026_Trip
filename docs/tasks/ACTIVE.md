# ACTIVE Task

Status: READY

## Goal

軽井沢旅行ページに、2026-08-16〜2026-08-23の全体予定をスマホで一目で把握できる「旅行週間カレンダー」を追加する。

このtaskは **旅行週間カレンダーを成立させ、既存の日別Plannerへの入口にする** 1 goalだけ。

## Required context

最初に次のfileだけを読むこと。

- `AGENTS.md`
- `docs/tasks/ACTIVE.md`
- `docs/trips/karuizawa/index.html`

軽井沢専用CSVは、カレンダーに表示する既存候補名・状態の確認が必要な場合のみ次を読む。

- `docs/trips/karuizawa/data/candidates.csv`

repo全体scan、神奈川旅行の調査、外部Web調査は不要。

## Scope

1. `docs/trips/karuizawa/index.html` の上部（旅行基本情報の後、既存詳細セクションより前）に、8/16（日）〜8/23（日）を一覧できる旅行週間カレンダーを追加する。
2. スマホを主利用環境とし、横に7列/8列並べる月間カレンダーではなく、日付ごとの縦型カード/行を基本とする。
3. 各日には、Repositoryですでに確定している情報だけを短く表示する。
   - 8/16（日）: 軽井沢へ移動、アウトレット17:30頃、新軽井沢花火大会、コテージチェックイン（実績）
   - 8/17（月）: コテージ内・周辺、18:45 ピザーラ夕食（実績）
   - 8/18（火）: 14時頃オンライン会議（確定制約）
   - 8/19（水）: 14時頃祖父を軽井沢駅で迎える、15:00〜17:00風越公園テニス（確定予定）
   - 8/20（木）: 父親終日会議・遠方移動不可、19:30 いろどりDINING 彩‐SAI‐夕食（確定予定）
   - 8/21（金）: 風越公園カーリング90分体験は「候補」であり予約確定として扱わない
   - 8/22（土）: 確定予定がない場合は「未定」等の中立表現
   - 8/23（日）: 確定予定がない場合は「未定」等の中立表現
4. 滞在中毎朝の朝食ブッフェ予定は、各日へ8回重複表示せず、カレンダー近くに「毎朝: 朝食ブッフェ」等の共通予定として簡潔に表示してよい。
5. 実績・確定予定/制約・候補・未定を、色だけに依存せずラベル/文字でも明確に区別する。
6. 各日付カードをタップ/クリックすると、同じページ内の既存「1日の予定を組み立てる」Plannerへ移動し、その日付をPlannerの選択日として設定する。
7. カレンダーからPlannerへ移動した時、既存PlannerのlocalStorage内容、固定anchor、候補順序を消したり初期化したりしない。
8. 8/21カーリング候補をカレンダーに表示しても、自動的にPlannerへ追加しない。
9. カレンダー表示のために、既存実績・固定予定・候補の意味を変更しない。
10. スマホ幅で、日付・主要予定・状態ラベルが横スクロールなしで読め、日付カードのタップ領域を十分確保する。

## Required behavior tests

- 8/16〜8/23の8日間が日付順に表示される。
- 8/17に「18:45」「ピザーラ」が実績として表示される。
- 8/18に14時頃オンライン会議が表示される。
- 8/19に祖父迎えと15:00〜17:00テニスが表示される。
- 8/20に終日会議制約と19:30 `いろどりDINING 彩‐SAI‐` が表示される。
- 8/21カーリングは「候補」と明示され、確定予定に見えない。
- 8/22・8/23に未確定情報を捏造していない。
- 状態は色だけでなく文字ラベルでも判別できる。
- 8/19の日付カードを操作するとPlannerの日付が `2026-08-19` になり、既存の祖父迎え/テニスanchorが表示される。
- 8/20の日付カードを操作するとPlannerの日付が `2026-08-20` になり、19:30夕食anchorが表示される。
- カレンダー操作で既存localStorage Planner dataが消えない。
- 既存候補選択、上下移動、Google Maps導線が壊れていない。
