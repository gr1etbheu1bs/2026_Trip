# 2026 Trip

親子科学旅行 Gプランの比較検討用HTMLサイトです。

## スマホ/Macで見る

GitHub Pagesの公開元を以下に設定します。

- Branch: `main`
- Folder: `/docs`

公開URLを開くと、`docs/index.html` が表示されます。

## 個人情報の扱い

GitHubに固定の自宅住所や予約済みホテルの詳細は置きません。

Topページの「出発地・宿泊先はこの端末だけに入力」欄へ、必要な時だけGoogle Mapsや予約メールからコピーして貼り付けます。入力内容はブラウザの `localStorage` にだけ保存され、GitHubには送信されません。

## 更新の流れ

GitHub Pages公開用は `docs/` です。

大きく更新した時は、作業用HTMLから `docs/` に反映します。

## 注意

料金、空室、営業日、天候、交通規制、駐車場条件は変わるため、出発前に必ず公式情報で再確認します。
